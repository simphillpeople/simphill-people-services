# Simphill People Services website

A simple static website built for GitHub Pages.

## Files
- `index.html` — website content and SEO metadata
- `styles.css` — design and mobile layout
- `logo.png` — Simphill logo
- `robots.txt` — search engine crawl rules
- `sitemap.xml` — search engine sitemap

## After publishing
Replace `YOUR-USERNAME` in `sitemap.xml` with your GitHub username.
Then uncomment and update the Sitemap line in `robots.txt`.

If you later buy a custom domain, update the sitemap URL again to the custom domain.
